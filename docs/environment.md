# Lab Environment

## CML Server 1

- Platform: Cisco Modeling Labs
- Hypervisor: VMware Workstation
- Host OS: Windows 11
- Host CPU: Intel Core i5-9300H
- Host RAM: 16 GB
- CML VM RAM: 8.5 GB
- CML VM vCPUs: 4
- CML virtual disk: 100 GB
- VMware network mode: Bridged

## Management Connectivity

The CML server is reachable from other devices on the home LAN through its bridged VMware network interface.

The CML management IP address is assigned using DHCP with a reservation on the local router.
