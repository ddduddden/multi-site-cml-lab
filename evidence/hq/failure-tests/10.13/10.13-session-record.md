# HQ-VP-10.13 — Diagonal Double Failure: hq-d1 + hq-r2

## Session record

**Evidence type:** session record.  

**Test date:** 6 October 2026.

Not retained: the complete original terminal transcript. This record contains
the measured values and route evidence recorded after the test.

## VLAN170 setup

```text
subnet:        10.10.70.0/23
hq-d1:         10.10.70.2
hq-d2:         10.10.70.3
HSRP VIP:      10.10.70.1
temporary a1:  10.10.70.4/23
```

Availability check before assignment:

```text
hq-d1 ping 10.10.70.4 repeat 3 = 0/3
ARP remained incomplete
```

Healthy traffic from 10.10.70.4:

```text
gateway:          5/5
hq-r1 Loopback0:  5/5
hq-r2 Loopback0:  5/5
```

Baseline gateway RTT:

```text
min/avg/max = 3/205/1007 ms
```

## First failure: hq-d1 stopped

After convergence:

```text
hq-d2 VLAN170: HSRP Active
hq-a1 VLAN170: Po20 Root/FWD

gateway:          5/5
hq-r1 Loopback0:  5/5
hq-r2 Loopback0:  5/5
```

A sourced ping was first entered on hq-d2 instead of hq-a1. IOS rejected the
source because 10.10.70.4 belonged to hq-a1. The check was rerun from hq-a1 and
passed.

## Second failure: hq-r2 stopped while hq-d1 remained down

hq-d2 retained one FULL OSPF adjacency:

```text
neighbour: hq-r1 / 10.255.10.7
interface: Gi3/0
```

hq-d2 route to hq-r1 Loopback0:

```text
10.255.10.129/32
metric 101
via Gi3/0
```

Traffic from hq-a1:

```text
VLAN170 gateway:  5/5
hq-r1 Loopback0:  5/5
```

Reverse-path evidence on hq-r1:

```text
10.10.70.0/23
via 10.255.10.6
out Gi0/4
metric 101
advertising router 10.255.10.132 / hq-d2
```

The settled forward and reverse route evidence therefore used the surviving
hq-d2 <-> hq-r1 cross-link.

## Recovery

Restore order:

```text
1. hq-r2
2. hq-d1
```

After hq-r2 returned with hq-d1 still down:

```text
hq-r2: four FULL adjacencies to hq-d2
```

After hq-d1 returned:

```text
hq-d1 VLAN170: HSRP Active
hq-d1: five FULL OSPF adjacencies
hq-a1: Po10 Root/FWD, Po20 Alternate/Blocking

gateway first check: 4/5 (.!!!!)
gateway repeat:      5/5
both edge loopbacks: 5/5
```

hq-r1 route to 10.10.70.0/23 returned to four metric-11 paths through hq-d1:

```text
10.255.10.0   via Gi0/0
10.255.10.8   via Gi0/1
10.255.10.10  via Gi0/2
10.255.10.12  via Gi0/3
```

The temporary Vlan170 source was then removed from hq-a1 and the default gateway
returned to 10.10.99.1.
