# HQ-VP-10.09 — hq-d2 Routed Isolation

## Session record

**Evidence type:** session record  

**Original source:** Cisco CLI captured in the 5 October 2026 live test session.  

Not retained: the complete original terminal transcript.

## Healthy baseline

The original session retained:

```text
hq-a1:
  Vlan199 10.10.99.4 up/up
  ip default-gateway 10.10.99.1
  VIP 10.10.99.1 = 5/5
  hq-r1 Loopback0 = 5/5
  hq-r2 Loopback0 = 5/5

hq-d2:
  five FULL OSPF neighbours
  VLAN199 HSRP Active
  Po20(SU)
  Po30(SU)
```

## Failure

All five routed links on hq-d2 were shut:

```text
Gi2/0
Gi2/1
Gi2/2
Gi2/3
Gi3/0
```

Po20 and Po30 remained up.

The original failure CLI was captured at approximately 07:58 UTC on 5 October.
The retained results were:

```text
hq-d2#show ip ospf neighbor
<no neighbours>

VLAN199:
  Active local
  VIP 10.10.99.1

hq-d2#show ip route 10.255.10.129
% Subnet not in table

hq-d2#show ip route 10.255.10.130
% Subnet not in table

Po20(SU)
Po30(SU)
```

From hq-a1:

```text
10.10.99.1:
  5/5

10.255.10.129:
  U.U.U
  Success rate is 0 percent (0/5)

10.255.10.130:
  U.U.U
  Success rate is 0 percent (0/5)
```

hq-d1 remained HSRP Standby for VLAN199 and retained successful routed
connectivity to both edge-router loopbacks:

```text
hq-d1 -> 10.255.10.129 = 5/5
hq-d1 -> 10.255.10.130 = 5/5
```

## Recovery

After all five routed links were restored, the live session retained:

```text
hq-d2:
  five FULL OSPF neighbours
  VLAN199 still HSRP Active

hq-a1:
  VIP 10.10.99.1 = 5/5
  hq-r1 Loopback0 = 5/5
  hq-r2 Loopback0 = 5/5
```
