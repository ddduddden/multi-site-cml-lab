
# Multi-Site CML Home Lab

A practical Cisco Modeling Labs project for developing networking, automation, and NetDevOps skills while documenting the lab for use in a technical portfolio.

## Project Goals

- Build a multi-site Cisco environment.
- Practise routing, switching, and troubleshooting.
- Develop Linux, Git, Python, and Ansible skills.
- Introduce network automation using Cisco APIs.
- Document configurations, verification, and troubleshooting for a technical portfolio.

## Environment

- Cisco Modeling Labs
- VMware Workstation
- Windows 11 hosts
- Physical home network connectivity

## Current Status

Initial CML server deployed and reachable across the local network.
